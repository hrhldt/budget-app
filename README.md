# 💸 Cashually

Your budget's new best friend. No sign-ups, no servers, no nonsense — just you, your money, and a single HTML file.

## What is it?

A slick little budget tracker that lives entirely in one `index.html` file. Open it in a browser. That's it. You're budgeting now.

## Features

- **Set a monthly budget** and watch it shrink (gracefully, we hope)
- **Track expenses** with names, amounts, and tags across 15 categories
- **Spending bar** that goes from chill purple → warning amber → yikes red
- **Daily guidance** so you know exactly how much coffee you can still afford
- **30 currencies** — from USD to NGN, pick your flavor
- **Dark mode** because your eyes deserve nice things
- **Glassmorphism UI** because flat design had its moment
- **Zero dependencies** beyond a couple of Google Fonts and FontAwesome icons

## How to use

1. Open `index.html`
2. Set your budget
3. Add expenses
4. Try not to cry
5. Repeat monthly

## Tech

- Single self-contained HTML file (~1200 lines)
- Vanilla JS, no frameworks
- CSS custom properties for theming
- `localStorage` for persistence
- `Intl.NumberFormat` for currency formatting
- Works via `file://` — no server needed
